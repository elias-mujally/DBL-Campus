# DBL Campus — منصة إدارة الدفعات الجامعية (Student Cohort Management Platform)

نظام متكامل متعدد المستخدمين (Multi-User Local Network Platform) مصمم لإدارة الدفعات الجامعية بكفاءة، بحيث يتشارك مندوب الدفعة ونائبه والمنسقون والطلاب المعلومات الأكاديمية، الجداول الدراسية، التكاليف، الإعلانات، الطلبات الجماعية وكشوف التأييد الرسمية (A4)، وتوزيع المهام عبر الشبكة المحلية دون الحاجة إلى خدمات سحابية مدفوعة أو مفاتيح API خارجية.

---

## 1. المزايا الرئيسية

1. **معمارية خادم محلي متعدد المستخدمين (Local Network Multi-User Server)**:
   - يعمل التطبيق عبر خادم مركزي (`Express + SQLite WAL`) يستمع على `0.0.0.0:3000`، مما يتيح للمندوب والطلاب الاتصال بالنسخة المركزية نفسها من هواتفهم وحواسيبهم المتصلة بالشبكة المحلية (Wi-Fi / LAN).
2. **نظام حسابات وصلاحيات دقيق (RBAC)**:
   - **مندوب الدفعة (`Representative`)**: صلاحيات إدارة الدفعة كاملة، تفويض المهام، ضبط الصلاحيات، تصدير نماذج الطلبات وكشوف التأييد، والنسخ الاحتياطي.
   - **نائب المندوب (`Deputy`)**: صلاحيات إدارية مفوضة وقابلة للتخصيص من قِبل المندوب دون منح الصلاحيات الحساسة تلقائياً.
   - **منسق أكاديمي (`Coordinator`)**: طالب مكلّف بمسؤولية أو أكثر (المحاضرات، التكاليف، الملفات، الإعلانات، أو متابعة الطلبات) بحساب واحد.
   - **طالب (`Student`)**: استعراض الجدول حسب مجموعته (`A` أو `B`)، تتبع تقدمه الشخصي في التكاليف، تنزيل الملفات المسموحة، تقديم الطلبات والمقترحات، وتأييد الطلبات الجماعية.
3. **نظام الطلبات والشكاوى وكشوف التأييد الرسمية (A4 RTL Print/PDF)**:
   - دورة حياة موثقة للمعاملة (`مسودة` ← `مفتوح للتأييد` ← `جاهز للرفع` ← `تم رفعه` ← `قيد الدراسة` ← `تمت الموافقة` / `مقبول بتعديل` / `تعذر التنفيذ` ← `مغلق`).
   - تأييد واحد لكل طالب مع إمكانية السحب قبل الإغلاق، ومنع تعديل النص الجوهري بعد بدء جمع التأييد دون إعادة تأكيد الموافقين.
   - تصدير وطباعة 3 مستندات رسمية بمقاس A4 واتجاه عربي RTL:
     1. **نموذج الطلب الرسمي**.
     2. **كشف تأييد الطلاب الإلكتروني** (مع عمود توقيع يدوي فارغ تماماً لعدم خلط التأييد الإلكتروني بالتوقيع القانوني الحي).
     3. **ملحق صفحات تكميلية للتوقيعات اليدوية الحية**.
4. **إدارة الجدول الدراسي وكاشف التعارضات الزمنية**:
   - كشف فوري للتعارضات في القاعات أو المدرسين أو المجموعات الطلابية.
   - تمييز بصري واضح بين **الجدول الرسمي المعتمد**، **التغيير المؤقت المؤكد**، و**المقترح قيد التنسيق**.
5. **تطبيق ويب تقدمي قابل للتثبيت (PWA)**:
   - واجهة عربية RTL كاملة، تصميم Mobile-first مع دعم الوضع الفاتح والداكن (`Light / Dark Mode`) وإمكانية التثبيت كتطبيق مستقل.

## 2. متطلبات التشغيل

- **نظام التشغيل**: Windows 10 / 11 (أو Linux / macOS).
- **بيئة التشغيل**: [Node.js](https://nodejs.org/) إصدار `20.x` أو `22.x` فما فوق.
- لا يتطلب أي قواعد بيانات خارجية أو حسابات سحابية أو مفاتيح API.

---

## 3. خطوات التشغيل السريع على Windows

### الطريقة الأولى: التشغيل المبسط بنقرة واحدة (Windows Batch Script)
1. افتح مجلد المشروع واضغط مرتين على الملف:
   ```cmd
   start-windows.bat
   ```
2. سيقوم السكربت تلقائياً بالتحقق من تثبيت الحزم، ثم يعرض لك عنوان الشبكة المحلية (`LAN IP` مثل `http://192.168.1.15:3000`) لمشاركته مع الطلاب على نفس الشبكة، ويشغل الخادم المركزي.

### الطريقة الثانية: التشغيل عبر الطرفية (Terminal / PowerShell)
```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تشغيل الخادم المركزي (Development / LAN Server)
npm run dev

# أو لبناء نسخة الإنتاج وتشغيلها:
npm run build
npm start
```
